# 🛡️ TaskGuardian

TaskGuardian é um monitor de desempenho do computador desenvolvido em **Python** utilizando **CustomTkinter**. O projeto foi criado para oferecer uma interface simples, intuitiva e acessível, permitindo que usuários leigos acompanhem a saúde e o desempenho do computador sem a necessidade de conhecimentos técnicos sobre hardware.

> **Projeto desenvolvido como parte do curso de Assistente de Tecnologias da Informação do Instituto Senac Ourinhos.**

---

## 📌 Funcionalidades

- 📊 Monitoramento do uso da CPU
- 💾 Monitoramento da memória RAM
- 🗄️ Monitoramento do armazenamento (disco)
- 📋 Listagem de processos em execução
- ⚡ Atualização das informações em tempo real
- 🛡️ Diagnóstico simplificado do desempenho do computador
- 🖼️ Interface gráfica moderna com CustomTkinter
- 🪟 Compatível com Windows
- 🐧 Compatível com Linux

---

## 🖥️ Tecnologias Utilizadas

- Python 3
- CustomTkinter
- Psutil
- Pillow

---

## 📦 Instalação

Instale as dependências utilizando:

```bash
pip install customtkinter psutil pillow pyinstaller
```

### Ubuntu / Debian

```bash
pip install customtkinter psutil pillow pyinstaller --break-system-packages
```

---

## ▶️ Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/PedroRoque5/teskGuardian.git
```

Entre na pasta do projeto:

```bash
cd teskGuardian
```

Execute:

### Linux

```bash
python3 main.py
```

### Windows

```bash
python main.py
```

## 🎯 Objetivo

O TaskGuardian tem como objetivo tornar o monitoramento do computador mais acessível para qualquer usuário.

Em vez de apresentar apenas números e informações técnicas, o sistema busca fornecer diagnósticos simples e recomendações claras para ajudar o usuário a compreender o estado do computador e identificar possíveis problemas de desempenho.
